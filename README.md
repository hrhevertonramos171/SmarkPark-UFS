
# SmartPark - Sistema de controle de estacionamento

Projeto da Fase 1 - Sistemas de informação

O SmartPark é um sistema simples de controle de estacionamento desenvolvido para registrar entrada, saída de veículos e faturamento do estacionamento.

## Integrantes

- Gabriel Oliveira
- Heverton Ramos
- Pedro Lucas

## Funcionalidades

- Registrar entrada de veículo
- Registrar saída de veículo
- Consultar vagas disponíveis
- Consultar faturamento e taxa de ocupação
- Relatório de movimentações
- Consultar tabela de preços
- Encerrar sistema

## Configurações do estacionamento

- Capacidade máxima: 20 vagas
- Tarifa por hora: R$ 5,00
- Horário de funcionamento: 06h às 22h
- Permanência mínima cobrada: 1h

## Arquivos do projetos

- main.py: menu principal
- movimentacao.py: responsável pelos registros 
- faturamento.py: responsável pelos cálculos
- relatorios.py: consultas e relátorios
- config.py: Constantes

## Requisitos

- Python 3.10 ou superior

## Como executar

- Baixe ou clone o repositório
- Abrir projeto no PyCharm.
- Rodar o arquivo no main.py
- Usar menu com as opções de acordo com o desejado
